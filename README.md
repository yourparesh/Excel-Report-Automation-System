
# Excel Report Automation System

A Python-based project that automates Excel report generation using Pandas and OpenPyXL.

## 🚀 Features

- Read student data from Excel files
- Automatically calculate total marks
- Calculate average marks
- Generate Pass/Fail results
- Rank students based on total marks
- Identify class topper
- Generate separate Pass and Fail reports
- Automatically format Excel reports
- Adjust Excel column widths automatically

## 🛠️ Technologies Used

- Python
- Pandas
- OpenPyXL

## ⚙️ Installation

First, clone the repository:

```bash
git clone https://github.com/yourparesh/Excel-Report-Automation-System.git
```

Open the project folder:

```bash
cd Excel-Report-Automation-System
```

Install required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python main.py
```

## 📊 Output

The system automatically generates three Excel reports:

1. `student_report.xlsx` – Complete student report with total, average, result and rank.
2. `passed_students.xlsx` – List of passed students.
3. `failed_students.xlsx` – List of failed students.

All reports are saved inside the `output` folder.

## 🎯 Project Objective

The main objective of this project is to reduce manual Excel work by automating calculations, result analysis, ranking and report generation using Python.
